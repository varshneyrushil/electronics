# Robotic-arm 3-pin interface breakout

Historical Mars Rover Manipal harness/interface PCB.

The surviving EAGLE schematic fans a 10-pin connector into three 3-pin interfaces. Each 3-pin interface carries two signal lines plus ground, providing a compact multi-way-to-serviceable-breakout arrangement for rover wiring.

## Included

- `source_eagle/` — original EAGLE schematic and board
- `source_altium_legacy/` — an Altium/SolidWorks PCB snapshot recovered from the later STM32 project archive
- `manufacturing/` — Gerber/drill outputs

This is team-project hardware; the folder documents my electronics contribution rather than claiming sole ownership of the rover system.
