# Camera interface PCB

Historical Mars Rover Manipal / Bagheera camera-interface design.

The surviving RAR contains EAGLE `.sch` and `.brd` source plus a full Gerber/drill set. The archive is preserved intact under `legacy_archive/`; see `ARCHIVE_MANIFEST.md` for the exact contents.

Detailed signal mapping is intentionally not reconstructed from memory without the extracted schematic.
