# Left-motor interface PCB

Historical Mars Rover Manipal / Bagheera left-motor interface design.

The surviving RAR contains EAGLE `.sch` and `.brd` source plus manufacturing outputs. It is preserved intact under `legacy_archive/`; see `ARCHIVE_MANIFEST.md`.

The manufacturing outputs indicate this board shares a closely related base/layout family with the camera interface, while the top-copper routing differs.
