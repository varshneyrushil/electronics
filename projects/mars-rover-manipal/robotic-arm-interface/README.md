# Robotic-arm interface PCB

Historical Mars Rover Manipal / Bagheera robotic-arm interface project.

The original RAR archive contains EAGLE schematic/board source and fabrication outputs. A second Altium/SolidWorks PCB snapshot was also recovered from the historical STM32 project directory.

The exact revision relationship between this fuller interface and the later `robotic-arm-interface-3pin` breakout has not been fully reconstructed, so both are preserved separately.

## Legacy EAGLE archive

`legacy_archive/roboticarmmmbagheera.rar` contains the original EAGLE schematic/board and Gerber outputs. See `ARCHIVE_MANIFEST.md` for its contents.
